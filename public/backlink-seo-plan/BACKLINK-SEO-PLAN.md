# MBK Portfolio + MBK Global — Backlink SEO Plan

**Purpose:** build relevant, earned links and consistent brand/entity references for `https://mr-bakhtawar.netlify.app/` and `https://mr-bakhtawar.netlify.app/`.

This tracker contains **159 backlink opportunities**, not 159 existing backlinks. A row becomes a backlink only after a real profile, editorial mention, directory listing, or content page is published and its link is publicly accessible. Availability, terms, moderation, link attributes, and eligibility vary.

## Priority plan

### Phase 1 — First 2 weeks (P1)
- Complete the existing personal and MBK Global profiles consistently: LinkedIn, GitHub, About.me, Linktree, social profiles, DEV, Behance/Dribbble if relevant.
- Use the personal portfolio for the person/profile destination and MBK Global for company/project destination. Do not point every profile to the same page automatically.
- Add the website link only in the platform's intended website field or a genuinely useful editorial context.
- Publish 2–3 original technical/project articles that demonstrate real work (for example: MBK TV project notes, API integration lessons, accessibility/performance improvements).

### Phase 2 — Weeks 3–6 (P2)
- Publish helpful technical articles and project case studies on relevant developer/publishing platforms.
- Submit genuine products/services to directories only if they qualify; use truthful descriptions and accurate contact/location information.
- Answer relevant community questions first; link only when it directly helps the answer.
- Ask clients/collaborators to mention a completed project when appropriate.

### Phase 3 — Ongoing (P3)
- Maintain a few creator/bookmark profiles only if they are used actively.
- Earn editorial links through useful resources, project releases, interviews, tutorials, and partnerships.

## Suggested destination mapping
- **Person / founder / portfolio:** `https://mr-bakhtawar.netlify.app/` and the dedicated founder profile page on that site.
- **Company / brand / services:** `https://mr-bakhtawar.netlify.app/`.
- **Projects:** link directly to the relevant live project (MBK TV, MBK Markets, MBK Downloader, Noor-e-Quran) only where the platform context matches.
- Use consistent name/brand spelling and the same official contact details. Do not invent registrations, awards, clients, reviews, office addresses, or credentials.

## Tracking procedure
1. Open the platform URL from the CSV and review its current rules.
2. Create or update a genuine profile; verify email/identity if required.
3. Add a destination URL only if the field is permitted and contextually relevant.
4. Paste the **published profile/page URL** into the tracker.
5. Inspect the public page to confirm the link works; record `nofollow`, `ugc`, `sponsored`, or other attributes only after checking.
6. Recheck after 30 days and note indexability/referral traffic. Search engines may not index every profile or count every link.

## Safety and quality rules
- Do **not** buy bulk backlinks, use automated link builders, spam comments/forums, create fake reviews, make doorway pages, or mass-create near-identical profiles.
- Avoid low-quality link farms and irrelevant directories. A high third-party Domain Authority score does not guarantee value or ranking impact.
- A `nofollow` or `ugc` link can still provide discovery/referral value; do not chase `dofollow` at the expense of relevance.
- No backlink list guarantees indexing, ranking, traffic, or a specific number of live links.
- Keep this tracker as an internal working file; it is not intended to be published as a public link directory on the portfolio site.

## Recommended monthly targets
- 5–10 high-fit profile/brand citations completed accurately.
- 2 genuinely useful technical/project articles.
- 2–4 earned mentions from collaborators, communities, clients, or relevant publications.
- Review Search Console Links report and referral analytics monthly; measure quality and relevance, not raw link count alone.
