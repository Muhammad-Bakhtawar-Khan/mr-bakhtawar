# SEO launch checklist

## Included in this package
- Unique page titles and meta descriptions for core pages
- Canonical URLs and social-sharing metadata
- Person and WebSite structured data on the home/profile pages
- Seven standalone, crawlable article URLs with BlogPosting structured data
- XML sitemap listing the main pages and article pages, with image sitemap entries
- `robots.txt` pointing to the sitemap
- Descriptive alt text for gallery images
- `SEO-KEYWORD-MAP.md` for page-by-page search intent

## Before launch
1. Confirm the deployed domain is exactly `https://mr-bakhtawar.netlify.app`. If not, replace it in canonical URLs, structured data, sitemap and robots.txt.
2. Deploy the files and check each URL returns HTTP 200.
3. Add the domain property to Google Search Console and verify ownership.
4. Submit `https://mr-bakhtawar.netlify.app/sitemap.xml` in Search Console.
5. Use URL Inspection on the home page, profile page, projects page and article URLs; request indexing for priority URLs.
6. Check structured data with Google's Rich Results Test / Schema Markup Validator.
7. Use Search Console's Performance report to track impressions, clicks, queries and indexing issues.
8. Add genuine, crawlable links from trusted profiles and relevant project sites; do not buy spam links.
9. Update article content with original screenshots, verified features, dates and lessons as the projects evolve.

## Important expectations
Sitemaps and SEO metadata help discovery; they do not guarantee indexing, ranking, a knowledge panel or sitelinks. Google selects sitelinks automatically. Avoid hidden keywords, doorway pages, fake reviews, mass-generated thin articles and purchased link schemes.

- [ ] Review `/services.html` on mobile and desktop and confirm all listed services match current capability and availability.
- [ ] Verify the live canonical domain before deployment; update the services canonical and sitemap if needed.
- [ ] Submit the updated sitemap in Google Search Console after deployment.
