Web Performance and User Experience Guide

Performance is part of usability: pages should show meaningful content quickly, remain stable as they load, and respond reliably to keyboard, touch and pointer input.

Prioritize what appears first

Identify the primary above-the-fold content and avoid lazy-loading the main visual when it is needed for the initial experience. Use fetch priority only for a genuinely important image and do not preload every asset.

Size images deliberately

Set width and height attributes when dimensions are known so the browser can reserve space. Use responsive image sizes where practical, preserve aspect ratio, and lazy-load suitable below-the-fold images. Do not rehost third-party images without permission.

Reduce font-loading delays

Avoid CSS @import chains for web fonts. Use explicit stylesheet links and preconnect only to origins actually needed. Provide a sensible fallback stack and use font-display: swap when self-hosting or configuring fonts.

Test responsive behavior

Check representative narrow mobile widths, tablet and desktop layouts. Look for horizontal overflow, clipped navigation, unreadable text, tap targets that are too small and forms that are hard to complete.

Measure rather than assume

Core Web Vitals goals are LCP at or below 2.5 seconds, INP at or below 200 milliseconds and CLS at or below 0.1. These are targets, not results; distinguish local lab tests from real-user field data and retest after deployment.
