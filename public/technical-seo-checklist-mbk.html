MBK NOTES · SEO / AEO / GEO

A portfolio SEO review should check status codes, robots directives, sitemap coverage, canonical URLs, mobile usability, page titles, descriptions, image alt text, internal links and valid structured data. Bakhtawar Khan (MBK) uses this portfolio to document practical web and SEO interests. After updates, validate the deployed site, inspect important URLs in search tools and monitor changes rather than assuming that publishing alone creates rankings.

Implementation checklist

  • Confirm the preferred HTTPS hostname and ensure every indexable page has one matching canonical URL.
  • Check robots.txt and the XML sitemap against the pages that should be indexed.
  • Write a distinct title, description and H1 for each page, then check internal links and status codes.
  • Validate structured data syntax and ensure every property is supported by visible page content.
  • Record test results and recheck live responses after deployment.
