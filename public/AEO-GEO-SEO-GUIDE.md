# AEO / GEO / SEO content guidance

Use concise, accurate, human-readable answers on the visible website. Keep each answer grounded in the owner's actual projects and services. Do not add invented credentials, awards, client outcomes, rankings or guarantees.

Suggested FAQ topics for the existing FAQ page:
- Who is Muhammad Bakhtawar Khan (MBK)?
- What is MBK Global?
- What kinds of digital projects has MBK built?
- Does MBK offer website development and API integration?
- What is the purpose of MBK TV, MBK Markets and MBK Downloader?
- How can someone contact MBK about a project?
- What technologies and areas is MBK currently exploring?

AEO/GEO practices:
- Answer the question directly in the first 1–2 sentences, then add helpful context.
- Use descriptive headings, meaningful internal links and visible text (not content available only in images or scripts).
- Add JSON-LD only when it accurately matches visible page content.
- Keep each page's title and description unique; avoid keyword stuffing and fake reviews.
- FAQ structured data does not guarantee a Google FAQ rich result; Google's FAQ rich result display has been retired.
- No markup, llms.txt file or AEO technique guarantees citation in AI answers.

Crawler policy:
- robots.txt asks listed AI crawlers not to access the site, while leaving Googlebot/Bingbot web search crawling allowed.
- robots.txt is not authentication. Some bots may ignore it, and content already copied or available elsewhere cannot be recalled.
- For stronger protection, keep confidential data off public pages and use authentication or server/CDN/WAF controls where supported.
