## Technical and structured-data rules

- Keep personal portfolio canonicals on `muhammad-bakhtawar-khan.vercel.app` and the brand entity URL on `mr-bakhtawar.netlify.app`.
- Use the stable person ID `https://mr-bakhtawar.netlify.app/#person` and organization ID `https://mr-bakhtawar.netlify.app/#organization` when representing the relationship.
- Use `sameAs` only for identity profiles. Keep project URLs in the project directory, not as substitutes for profile URLs.
- Keep structured data consistent with visible page copy. Do not mark sample feedback as real reviews.
- Keep `404.html` and `thank-you.html` out of the sitemap and mark them `noindex,follow`.
- `robots.txt` allows `OAI-SearchBot` for search discovery and disallows `GPTBot` under the current owner policy. These controls are separate; neither setting guarantees inclusion in search results.
- `llms.txt` is an optional navigation aid, not a ranking or citation mechanism.
- Do not use the meta keywords tag as a Google ranking strategy. Focus on unique titles, useful copy, accessible links, correct canonicals and technical quality.
