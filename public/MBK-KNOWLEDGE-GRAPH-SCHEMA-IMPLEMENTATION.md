# MBK Knowledge Graph Schema Implementation

Updated `index.html` with one unified Schema.org JSON-LD `@graph` connecting `Person`, `Organization`, `WebSite`, `WebPage`, `BreadcrumbList`, and four `SiteNavigationElement` nodes. The Person entity uses the existing portrait asset and established profile URLs. MBK Global is represented as the organization and provider of the described service catalog.

## Deployment and verification
1. Deploy the full project to the existing Vercel site.
2. Test the homepage URL in Schema Markup Validator and Google Rich Results Test.
3. In Google Search Console, inspect the homepage, test the live URL, request indexing, and review sitemap/indexing reports.

Schema does not guarantee a Knowledge Panel, AI Overview citations, or sitelinks. Confirm the visible page content and every linked URL after deployment.
