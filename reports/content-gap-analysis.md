## Gaps that need evidence

1. Original project role, repository, architecture decisions, screenshots,
   current availability and limitations for each promoted project.
2. Ecommerce delivery examples, actual supported platforms and integration
   boundaries before creating a dedicated service page. Shopify expertise is not
   established by a generic ecommerce mention.
3. Verified professional experience, qualifications and dates for resume content.
4. Search Console query evidence for genuine unanswered questions. Existing FAQ
   questions are content-derived opportunities, not measured search demand.
5. Permission and actual delivery context before testimonials, named clients,
   results or new country/local landing pages.

## Editorial quality gates

Do not pad pages to a word count. Gallery/contact directories can be concise and
useful; short educational and project notes need human review against intent.
Each calendar item specifies an existing URL, research requirements, supporting
links and approval gate. A missing fact stays missing. Review original usefulness,
accessibility, author attribution and dated external references before publishing.
